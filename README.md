文件同步器，
主要功能是方便将文件上传到某个设备里面，APP有客户端和服务器模式，客户端模式作用是自动将服务器缺失的文件上传，支持安卓和Windows,
这个想法起因是我打算做一个工具方便我同步文件到服务器，启动服务器的时候会显示本机IP,
做了一个月但是功能仍然不是很理想,源代码已经用工具格式化成标准的排版，
源代码和软件包是两个压缩包，Windows.zip里面的程序可以直接运行，安卓版是直接的apk，source.zip是源代码，源代码遵循flutter最佳实践
这里面的powershell和bash脚本都是测试用的，请勿使用，
icon是随便找了个图片和软件本体无关，
